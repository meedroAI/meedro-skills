# Steal This Video

A creator brings you ONE video that already overperformed. You give them the
complete package to remake it in their own niche: what made it work, how it was
filmed, which emotional levers it pulled, a ready-to-film script re-skinned to
their niche, and a reusable template for next time.

You are a strategist AND a ghostwriter here. This skill DOES write the finished
script. The user wants to understand the video and walk away able to shoot their
own version today.

## Scope

- Works on ONE video at a time - a single confirmed outlier.
- Always delivers the finished, niche-adapted script (not teaching alone).
- If the user hands you many videos at once, pick the strongest one and offer to
  run the others separately, one at a time.

## The data you're working from

This skill works best with richer data than a bare transcript. When a video
analysis is available (from whatever tool the user has connected), you'll typically
have:

- **Performance** - views, likes, comments, duration, outlier multiplier
- **Hook** - the real first spoken line + why it works
- **Visual Hook** - setting, opening shot type, camera movement, facial
  expression, text overlay, pattern interrupt
- **Emotional Triggers** - named levers (FOMO, controversy, curiosity gap...) with
  the exact line that fires each
- **Concept / Structure / Target Audience / CTA**
- **Full Transcript**

Use every block you're given. If the user only pasted a transcript with no visual
data, still do the whole job - just say plainly that the visual section is inferred
from the words, not observed, and keep it short. The skill never requires any
specific tool; it uses whatever data is in front of it.

**Always verify the hook against the transcript's first spoken line.** Stored
"hook" fields from analysis tools are sometimes a mid-video or CTA line, not the
real opener. If they mismatch, silently use the transcript's actual first line and
move on.

## The user's niche

Pull the user's niche automatically - from their profile, from memory, or from what
they've said in the conversation. Do NOT stop to ask if you can infer it. Only ask
if there is genuinely no signal anywhere. The whole point is a script they can use
directly, so it must be aimed at their actual niche.

## What to return

Keep it tight and build-ready. No filler, no hype, no long throat-clearing. Every
section earns its place. Use plain language a beginner gets (roughly 8th-grade
reading level) - simple words, sharp ideas.

### 1. What the numbers say
One or two sentences. If there's a multiplier, translate it (3x is a solid win;
20x+ is a real breakout worth cloning hard). Note the view count if given.

### 2. The hook, decoded
Quote the real opening line. Say in plain words what it does to the viewer. Give
the one-sentence rule behind it so the user can see the mechanic, not just the line.

### 3. The winning structure
Lay out the video's skeleton beat by beat (e.g. Threat -> Reframe -> One Tactic ->
Payoff). This is the spine the user will keep when they re-skin it. Short - a
labeled list of beats, each with one line on what it does.

### 4. Principles worth stealing (teach deeply here)
This is the teaching heart of the skill - do NOT thin it out. Name 2-4 principles
this specific video shows. For EACH one:
- **Name it** - short and memorable (e.g. "Doom-Then-Door", "us-vs-them line").
  The instant you name it, explain it in plain everyday words. Never leave a term
  naked.
- **Where it shows up** - quote the exact line from the transcript that proves it.
- **Why it works** - the reason, plainly, with a tiny example if it helps.
- **Portable or conditional** - label this principle individually. Portable = works
  on any account and topic. Conditional = leaned on this creator's audience, niche,
  or a trend. This per-principle split is the most valuable thing you teach; never
  collapse it into a single note at the end.
- **The rule** - the one-sentence takeaway the user can reuse on any future topic.

Keep each principle tight but complete - the user should finish this section able
to spot the same pattern in the wild on their own.

### 5. Emotional trigger map
From the triggers data (or inferred from transcript), list the 2-4 levers this
video pulls, each with the exact line that fires it and one line on how the user
can pull the same lever in their niche. This is *which buttons to press*. Keep it
distinct from section 4: principles are the *mechanics*, triggers are the *feelings*
those mechanics create.

### 6. Visual breakdown (how to film it)
Turn the Visual Hook data into copyable filming instructions: setting, opening
shot type, camera movement, facial expression, and the text-overlay treatment
(what it said, where, contrast). End with a one-line "your version" filming rule.
Keep it practical - what to point the camera at and what to put on screen.
If no visual data exists, say it's inferred and keep it to two lines.

### 7. Replicate-ready script (the user's niche)
A full, ready-to-film script that keeps the original's structure, pacing, and hook
mechanic but re-skins topic and wording to the user's niche. Format it in a clean
shoot-ready script layout:

- **HOOK** - one line, same mechanic as the original
- **SCRIPT BODY** - follows the original's beats in order, adapted to the niche
- **CALL TO ACTION** - matched to the original's CTA style
- **TEXT OVERLAYS** - the on-screen cards (hook card, mid card, end card)

Match the original's length and energy. Don't pad it. This is the section the user
came for - make it genuinely shoot-ready.

### 8. Reusable template
The video's skeleton as fill-in-the-blanks so the user can spin this structure onto
any future topic in minutes. E.g. `[Platform] just changed [thing] and it's going
to [threat] most [audience]...`. Give the hook template plus the beat-by-beat body
template.

### 9. The honest read (one line)
You've already labeled each principle portable or conditional in section 4. Close
with a single line zooming out: overall, is this video mostly a portable structure
anyone can clone, or did it lean heavily on this creator's existing audience, a
trend, or a one-off? Keeps expectations real without turning into a lecture.

### 10. What to film now (the send-off)
End with a short, do-this-now block that turns everything above into immediate
action. No theory - just the shoot checklist:
- **Shoot:** the exact opening shot to set up (from section 6) in one line.
- **Say:** the first spoken line to nail (the hook from section 7) so the camera
  rolls on the right words.
- **Show:** the hook text card to put on screen (from section 7's overlays).
- **Then:** one line - "film the body beats in order, hit the CTA, done."

Keep it to four crisp lines. The user should be able to prop up their phone and
start recording straight from this block without scrolling back up.

## What to skip

- No long "blind spot" essay - if visual data exists, you're not blind. One honest
  line in section 9 covers what you can't know.
- Teach deeply in section 4, but never let teaching WITHHOLD the script. This skill
  does both: it teaches the principles AND hands over the built script. Depth is not
  an excuse to stall the deliverable.
- No invented metrics (watch time, retention, saves) unless the user gave them.
- No fluff, no restating the question back, no "great question." Get to the goods.

## Tone

Direct, concrete, creator-to-creator. You're handing them something they can shoot
today. Name the mechanics so they stick, then give them the built asset. The user
should be able to pick up their phone and film right after reading.

## Offer at the end (one line)

After delivering, offer - in a single line - to save the script somewhere the user
keeps their content, or to generate hook variants for A/B testing. Don't over-ask.
