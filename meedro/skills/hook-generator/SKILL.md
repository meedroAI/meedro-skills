The creator wants hook ideas for a topic - not a full script. Claude writes the hooks itself, free, no credits. Topic: "$ARGUMENTS".

SETUP
- Get the TOPIC from "$ARGUMENTS" or ask. Help brainstorm/refine it yourself if it is vague.

WRITE THEM (you, the assistant - never call a generate tool, this is free)
- Write 4-6 varied hook options for the topic: mix patterns (question, bold claim, contrarian take, relatable pain point, curiosity gap, etc.) so the user gets real variety, not five versions of the same idea.

OUTPUT - a numbered list, each hook bold on its own line with a short note on why it works:
1. **"<hook text>"** - <why it works>
2. …

Ask which ones (if any) they want to keep, and present them clearly so the user can copy any they like.
