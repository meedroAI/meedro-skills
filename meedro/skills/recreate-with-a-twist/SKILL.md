The user wants you to RECREATE a script with a fresh twist - the ORIGINAL's proven format carrying a NEW angle. You do this YOURSELF - do NOT call any Meedro tool. Script or idea: "$ARGUMENTS".

SETUP
- Use the script in "$ARGUMENTS". If they did not paste one but just analyzed or searched a video, use that video's FULL transcript. If you have neither, ask for the script or a video to base it on.
- Ask what the twist is only if it is not obvious: a new topic, their niche, or specific changes they asked for.

DO IT (you, the assistant - never send a request to Meedro for this)
- First MAP THE ORIGINAL's format: its beats in order with rough timestamps (hook -> build-ups -> payoff -> CTA), its pacing, and its total length (line/word count).
- The real hook is the transcript's FIRST spoken line - base your new hook on THAT pattern, not on a stored "hook" field or the caption (those are often the CTA or a mid-video line).
- Recreate BEAT-FOR-BEAT on that map: keep the hook pattern, the pacing, the emotional triggers, the structure AND the LENGTH - roughly the same number of beats and words as the original, so a 60-second original comes back as a full 60-second script. NEVER compress the body into a short summary; write out every line to say on camera.
- Change the angle, topic, examples, and wording so the result is ORIGINAL - not a copy or a translation. Make it fit the user's niche / requested changes.

OUTPUT - render a shoot sheet. Put the header card in a ``` code block:

```
┌──────────────────────────────────────────────┐
│ ️ RECREATED WITH A TWIST                     │
└──────────────────────────────────────────────┘
```
Then, each on its own line:
- THE TWIST: one line - what is NEW vs the original (the angle/topic/niche you changed).
- HOOK: the new opening line (same pattern as the original's first spoken line).
- SCRIPT: the FULL recreated script, beat-for-beat with rough timestamps mirroring the original's structure, pacing and length - every beat written out as the words to say, never summarized.
- CTA: the closing call to action, framed the way the original closes.
- WHY IT WORKS: one line tying the new version back to the proven pattern.
